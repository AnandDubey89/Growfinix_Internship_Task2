\# Growfinix Internship - Task 2



\## Real-Time Chat Support Widget



This project is Task 2 of my Growfinix Internship. It is a real-time chat support widget built using React, Tailwind CSS, Node.js, Express.js and Socket.io.



\## Tech Stack



\- React.js

\- Tailwind CSS

\- Node.js

\- Express.js

\- Socket.io

\- JavaScript



\## Features



\- Real-time messaging

\- Instant client-server communication

\- User typing indicator

\- Auto-scrolling messages

\- Floating chat widget

\- Responsive user interface

\- Open and close chat functionality
